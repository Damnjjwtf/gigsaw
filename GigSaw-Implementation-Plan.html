The Five Core Modes (Tier 1 + 2)

1. /gigsaw arbitrage — Intelligence Arbitrage Engine ★

  • What it does: Takes a job listing and reveals what the role is becoming in 12-18 months
  • Key design: Two-stage prompting, 5-step sequential process with checkpoints, 6-section markdown output
  • Input: Job URL or pasted job description
  • Output: data/arbitrage/[company]-[role].md with ROLE AS WRITTEN, ROLE AS BECOMING, THE GAP, JJ'S POSITION, INTERVIEW REFRAME, PROOF BUILD SUGGESTION
  • Quality: Specific AI vulnerabilities (not vague), honest about role transformation likelihood, grounded in shipped proof

2. /gigsaw propose — Role Proposal Generator ★

  • What it does: Analyzes a company's current job postings, finds what role is missing, writes it for them
  • Key design: Three gap-detection strategies (skill overlap, responsibility fragmentation, seniority ladder)
  • Input: Company name + their current listings (from jobs.json or user pastes)
  • Output: proposals/[company]-role-proposal.md (1-2 pages, dense, specific)
  • Quality gates: 60%+ skill overlap required, proposed role must be distinct, JJ's work must connect

3. /gigsaw setup — Interview Agent v2

  • What it does: 6-round structured conversation to generate your profile.json
  • Rounds: Identity → Shipped Work → Problem Patterns → Profile → Targets → Narrative
  • Key design: 2-3 core questions per round, 1-clarification follow-up strategy, 25-35 min total
  • Output: profile.json with build_capability, shipped_work[], problem_patterns + all traditional fields
  • Quality gates: URLs required for shipped work, capabilities linked to proof, vague answers flagged

4. /gigsaw search — Job Search Orchestration

  • What it does: Scrapes LinkedIn + Indeed using your target roles/locations
  • Key design: Apify HTTP REST (not SDK), query generation from profile targets, composite dedup key
  • Input: profile.json targets (roles × locations)
  • Output: data/jobs.json with full schema (dedup_key, sources[], urls{}, target_match{}, metadata)
  • Speed: 2-3 minutes real-time, 60%+ matching jobs

5. /gigsaw evaluate — Job Evaluation Engine

  • What it does: Scores each job across 10 dimensions, assigns A-F grade
  • Key design: Gate-pass logic (Role Match 6+, Skills 5+ required), weighted GPA, 10-dimension scoring
  • Dimensions: Role Match (gate), Skills (gate), Build-Fit (15%), Arbitrage (20%), Company (10%), Compensation (8%), Location (8%), Growth (12%), Network (7%), Portfolio (8%)
  • Output: data/evaluations/[company]-[role].md with detailed breakdown + A-F grade
  • Quality rule: Strongly recommend against applying below B-

Key Design Decisions

Decision Rationale
Two-stage prompting (Arbitrage) Stage 1 does analysis; Stage 2 formats output. Cleaner, more reliable.
Checkpoints in Arbitrage User can correct after each step. Not a black box.
Three gap-detection strategies Different companies have different gaps. Try all three, pick best match.
Interview: 1 clarification then flag Don't re-ask forever. If answer is vague after 2 tries, flag it and move on.
Apify HTTP REST (not SDK) Lighter weight, full control, easier debugging. Skip dependency bloat.
Dedup on title+company+location Stable across platforms. Better than URL (which changes between sources).
Gate-pass logic in Evaluate Role Match 6+ and Skills 5+ are hard gates. If either fails, grade floors to D+.
Arbitrage weight (20%) Core differentiator. Heaviest weight drives focus on role transformation.

Success Verification

Unit Tests (Per Mode)

  • setup.md: Interview produces valid profile.json; all required fields populated; quality_score ≥ 0.7
  • search.md: Apify call succeeds; returns ≥5 jobs; dedup removes cross-posted jobs; JSON schema valid
  • evaluate.md: Grade is between A-F; gate-pass logic blocks inappropriate matches; weights sum to 1.0
  • arbitrage.md: Report has all 6 sections; trajectory is plausible (not vague); proof points to shipped work with URLs
  • propose.md: Gap is specific (not generic); proposed title distinct from existing roles; confidence score justified

Integration Tests (End-to-End)

  1. Run setup → generates profile.json ✓
  2. Run search → generates jobs.json with ≥10 listings ✓
  3. Run evaluate on jobs → grades range from A to F ✓
  4. Run arbitrage on top-graded job → outputs 6-section markdown report ✓
  5. Run propose on company → identifies gap, outputs proposal.md ✓
